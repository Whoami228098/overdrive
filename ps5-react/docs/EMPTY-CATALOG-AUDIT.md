# Empty catalog startup audit

Overdrive 1.0.10. The user's 2026-10-22 console trace reported a module-initialization
exception near bundle line 17582. The bundle extracted from the previously
delivered Minimal ELF has SHA-256
`4b5910a48c0079b18bf4c5e4b43aa43d5c6e68909882012a9a5090b02489d743`,
matching the build receipt. Lines 17582–17583 initialize `POPULAR` then access
`POPULAR[0].id`. The root eval ends at line 22145, matching the reported trace.

The repository-wide search covered `games[...]`, `gamesN[...]`, and their
`.at(...)` equivalents in JavaScript, JSX, TypeScript, Python and native source.
Derived catalog lists and first-element reads were reviewed separately.

| Site | Result |
| --- | --- |
| `browse/PopularRail.jsx`, derived `POPULAR[0].id` | Fixed: check length, omit empty section and focus target. |
| `browse/Spotlight.jsx`, derived `featured[slides.active]` | Fixed: omit empty spotlight, guard stale index, do not prefetch an empty list. |
| `browse/useSlides.js`, modulo by catalog count | Fixed: no timer when the slide count is zero. |
| `browse/GenreRail.jsx` and `TopCharts.jsx` | Omit empty sections and individual empty charts. |
| `search/Suggestions.jsx` | Omit empty popular heading; preserve search history. |
| `state/download-queue.js`, two `games[0]` reads | Already guarded by `games.length !== 1` returning first. This list contains extracted paths, not catalog records. |
| `browse/Catalog.jsx`, `b.games[i]` | Both lengths are compared first; the index comes from `a.games.every`. Empty lists do not invoke the callback. |
| `search/match.js`, `games[i]` | Indices are generated by iterating the same module-stable catalog. Empty search and nonempty-query cases return empty arrays. |
| `tools/import-superpsx.py`, five `games[key]` sites | Dictionary lookups, not first-array-element access; keys come from the importer's validated record set. |

The eight behavioral regressions in `app/browse/empty-catalog.test.mjs` cover
empty catalogs, user games without art, populated sections, stale slide indices,
search history and safe existing indexed reads. Against the previous native-image
source (`09a3378`) six fail and two pass. All eight pass with the fixes. This
checks the affected application paths; it does not prove universal PS5 stability.
